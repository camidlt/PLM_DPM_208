Du capteur ESP32 au passeport

Le boîtier BMS est un vrai microcontrôleur. Il mesure, il envoie, le serveur décide. Aucune règle métier dans le firmware : la santé de chaque module est calculée côté passeport.

{{ icon('cpu', 'lg') }}

ESP32 · 5 entrées analogiques

Une broche par module (GPIO 34, 35, 32, 33, 39). La lecture devient une résistance interne en mΩ ; le module 3 simule le défaut du défi 1.

{{ icon('wifi', 'lg') }}

Wi-Fi · HTTP toutes les 3 s

L'ESP32 rejoint le même réseau que le PC et envoie un JSON sur /api/telemetry. Le Bluetooth reste actif pour le débogage.

{{ icon('network', 'lg') }}

Graphe · Module, Measurement, Alert

Chaque mesure met à jour le nœud Module et s'ajoute à son historique. Au troisième dépassement consécutif, une alerte et un événement sont créés.

{{ icon('gauge', 'lg') }}

Critique : au-delà du maximum sur 3 mesures consécutives. Alerte ouverte, historique mis à jour.
